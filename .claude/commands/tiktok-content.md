# Conteúdo para TikTok

Skill para criar conteúdo otimizado para TikTok — roteiros, estratégia de trends, e crescimento orgânico.

## O que esta skill entrega

1. Roteiros otimizados para TikTok (15s-3min)
2. Identificação de trends adaptáveis ao nicho
3. Estratégia de crescimento orgânico
4. Hooks especializados para TikTok
5. Copies otimizadas para a plataforma

## Diferenças do TikTok vs Instagram

| Aspecto | TikTok | Instagram Reels |
|---------|--------|----------------|
| Duração ideal | 21-34s (sweet spot) | 15-30s |
| Hook | Primeiros 1-2s (brutal) | Primeiros 3s |
| Texto na tela | Quase obrigatório | Recomendado |
| Som/Áudio | Crucial (trending sounds) | Importante |
| Hashtags | 3-5 (menos é mais) | 10-20 |
| Tom | Mais cru, autêntico | Mais polido |
| Storytelling | Rápido, cortes frequentes | Mais fluido |

## Formatos que Performam no TikTok

### Educativo Rápido (15-30s)
```
📱 TELA: [gancho visual]
🎤 "hook de 1 segundo"
🎤 "3 dicas rápidas, uma por corte"
🎤 "CTA: salva pra não esquecer"
🎵 som trending de fundo (baixo)
```

### Story Time (30-60s)
```
📱 TELA: "uma coisa que ninguém sabe..."
🎤 "história pessoal com virada"
🎤 "aprendizado no final"
🎵 som ambiente ou trending
```

### Trend Adaptada
```
📱 Usar o template/som trending
🎤 Adaptar o conceito do trend pro nicho
⚡ Postar nas primeiras 48h do trend
```

### POV / Situação
```
📱 "pov: [situação relatable]"
🎤 Atuação rápida da situação
😂 Humor ou identificação
```

### Antes/Depois
```
📱 Transição visual
🎤 "antes: [problema]"
🎤 "depois: [resultado]"
🎵 som de transição trending
```

## Estrutura do Roteiro TikTok

```
🎬 ROTEIRO TIKTOK: [título]

⏱️ duração: [X segundos]
🎵 som sugerido: [trending sound ou original]
📱 formato: [educativo/storytime/trend/pov/antes-depois]

━━━━━━━━━━━━━━━━━━━━━━━

📱 TEXTO NA TELA:
[copy principal — max 2 linhas, grande, legível]

🎤 ROTEIRO:
[0-1s] "HOOK — frase que PARA o scroll"
[1-5s] "Contexto rápido"
[5-20s] "Conteúdo principal — cortes frequentes"
[20-25s] "CTA ou punchline"

✏️ DESCRIÇÃO:
[até 300 caracteres com keywords]

#️⃣ HASHTAGS:
[3-5 relevantes + trending]

━━━━━━━━━━━━━━━━━━━━━━━

💡 DICAS:
- [timing, edição, som]
- [melhor horário para postar]
- [como maximizar distribuição]
```

## Regras de Qualidade

- Hook em 1 segundo (TikTok é mais rápido que Instagram)
- Texto na tela SEMPRE (muitos assistem no mudo)
- Cortes frequentes (a cada 2-3s)
- Autenticidade > produção (câmera frontal funciona)
- Usar trending sounds quando possível
- Responder comentários com vídeo (boost de algoritmo)

## Checklist de qualidade

- [ ] O hook é de 1-2 segundos (não mais)?
- [ ] Tem texto na tela (legível)?
- [ ] A duração está no range ideal (21-34s)?
- [ ] O formato é nativo do TikTok (não parece ad)?
- [ ] As hashtags são relevantes e poucas (3-5)?
- [ ] O tom é autêntico e conversacional?
