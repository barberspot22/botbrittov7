# Análise de Concorrência em Redes Sociais

Skill para analisar concorrentes e referências, identificando oportunidades estratégicas.

## O que esta skill entrega

1. Análise comparativa de perfis concorrentes
2. Identificação de estratégias vencedoras dos concorrentes
3. Análise SWOT competitiva para redes sociais
4. Oportunidades de diferenciação
5. Benchmark de métricas e performance
6. Recomendações acionáveis

## Coleta de Informações

1. **Perfil do cliente** — @ e plataforma
2. **Concorrentes** — 3-5 perfis para analisar (ou pedir sugestão)
3. **Tipo de análise** — completa, específica (conteúdo, visual, copy), ou rápida

## Metodologia de Análise

### Para cada concorrente, coletar via browser:

```
📊 PERFIL: @concorrente

📈 Métricas visíveis:
- Seguidores: [número]
- Posts: [quantidade total]
- Frequência: [posts por semana estimado]
- Engajamento médio: [curtidas + comentários / posts recentes]

🎨 Identidade visual:
- Estilo: [clean/colorido/escuro/editorial]
- Uso de cores: [paleta predominante]
- Qualidade de produção: [baixa/média/alta]

📝 Conteúdo:
- Tipo dominante: [reels/carrosséis/posts]
- Temas recorrentes: [lista]
- Tom de voz: [formal/informal/divertido]
- Frequência de stories: [ativo/moderado/raro]

🏆 O que funciona:
- Top 3 posts por engajamento: [descrição]
- Padrão dos posts que mais engajam: [análise]

❌ Pontos fracos:
- [fraquezas identificadas]
```

### Análise SWOT Competitiva

```
📊 ANÁLISE SWOT — Seu perfil vs Concorrência

FORÇAS (do seu perfil):
✅ [o que faz melhor que os concorrentes]

FRAQUEZAS (do seu perfil):
⚠️ [onde os concorrentes são melhores]

OPORTUNIDADES (mercado):
🔵 [lacunas que ninguém está preenchendo]

AMEAÇAS (externas):
🔴 [riscos competitivos]
```

## O que analisar

1. **Conteúdo que funciona**: Que tipo de post performa melhor?
2. **Formato dominante**: Reels, carrosséis, posts?
3. **Tom de voz**: Como falam com o público?
4. **Frequência**: Quanto postam?
5. **Visual**: Como é a identidade visual?
6. **Engajamento**: Como é a interação com seguidores?
7. **Stories**: Usam ativamente?
8. **Bio**: Como se posicionam?
9. **CTAs**: Como direcionam para conversão?
10. **Lacunas**: O que NÃO estão fazendo que seria oportunidade?

## Checklist de qualidade

- [ ] Analisou pelo menos 3 concorrentes?
- [ ] Os dados são reais (coletados, não inventados)?
- [ ] A SWOT é específica (não genérica)?
- [ ] As oportunidades são acionáveis?
- [ ] A matriz comparativa está preenchida?
- [ ] As recomendações são concretas com próximos passos?
