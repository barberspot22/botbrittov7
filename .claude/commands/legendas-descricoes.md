# Legendas e Descrições Otimizadas

Skill para criar legendas e descrições estratégicas para qualquer tipo de conteúdo em qualquer plataforma.

## Tipos de Legenda

### Legenda Curta (Reels/TikTok)
```
[1-2 linhas diretas]
[emoji] CTA rápido

#hashtags
```
Max: 50-100 caracteres. Foco em complementar o vídeo, não repetir.

### Legenda Média (Posts/Carrosséis)
```
[Hook — primeira frase que para o scroll]

[Corpo — 3-5 linhas de valor]

[CTA — ação específica]

.
.
.
#hashtags
```

### Legenda Longa (Storytelling)
```
[Hook emocional]

[História — começo, meio, virada]

[Reflexão/aprendizado]

[CTA emocional]

.
.
.
#hashtags
```

### Descrições Especiais

**Stories Highlights:**
- Nome: max 10 caracteres, direto
- Exemplos: "dicas", "bastidores", "clientes", "serviços"

**Bio:**
```
[O que faz] [emoji]
[Resultado/prova social] [emoji]
[CTA] ↓
```

**YouTube:**
```
[Resumo com keyword — primeiros 150 chars]
[Detalhamento]
[Timestamps]
[Links]
[Tags]
```

## Framework de Legenda em 4 Passos

1. **HOOK** — prender atenção (pergunta, contradição, dado)
2. **VALOR** — entregar conteúdo (dica, história, insight)
3. **PROVA** — credibilidade (exemplo, resultado, depoimento)
4. **CTA** — próximo passo (comentar, salvar, clicar)

## Regras de Qualidade

- Primeira frase é a mais importante (truncamento)
- Parágrafos curtos (máximo 3 linhas)
- Emojis como marcadores, não decoração
- CTA específico (não "clique no link")
- Lowercase para Instagram/TikTok
- Hashtags separadas do texto principal

## Checklist de qualidade

- [ ] O hook funciona sozinho (sem ver a imagem)?
- [ ] O CTA é específico e acionável?
- [ ] O texto está no tom da marca?
- [ ] Respeita limites de caracteres da plataforma?
- [ ] Hashtags são relevantes e estratégicas?
- [ ] Parágrafos estão curtos e escaneáveis?
