# Copywriting para Redes Sociais

Skill para criar textos persuasivos e otimizados para todas as plataformas de redes sociais.

## O que esta skill entrega

1. Legendas otimizadas por plataforma (Instagram, TikTok, LinkedIn, X, etc.)
2. CTAs estratégicos que geram ação
3. Bios de perfil que convertem
4. Threads completas (X/Twitter, LinkedIn)
5. Copies de anúncios (Meta Ads, TikTok Ads)
6. Textos de stories com sequência estratégica
7. Descrições de produtos para social

## Frameworks de Copywriting

### AIDA (Atenção → Interesse → Desejo → Ação)
Usar para posts de venda direta ou lançamento.

### PAS (Problema → Agitação → Solução)
Usar para conteúdo educativo que leva à conversão.

### BAB (Before → After → Bridge)
Usar para casos de transformação e depoimentos.

### Hook → Story → Offer
Usar para reels e vídeos com CTA de venda.

## Estrutura por Plataforma

### Instagram (Feed/Carrossel)
```
[HOOK — 1 linha que para o scroll]

[CORPO — 3-5 linhas de conteúdo]

[CTA — chamada para ação clara]

.
.
.
[HASHTAGS — 5-15 relevantes]
```

Regras:
- Máximo 2.200 caracteres (ideal: 150-300 para posts rápidos, 800-1500 para educativos)
- Primeira linha é tudo — o Instagram trunca depois de 2 linhas
- Usar quebras de linha para criar respiro visual
- Emojis como marcadores visuais, não como decoração
- Hashtags após 3 pontos de separação (.)

### Instagram Reels
```
📱 tela inicial: [copy curta, max 2 linhas, lowercase]

📝 legenda: [texto curto e direto, max 5 linhas]

#️⃣ hashtags: [5-10 relevantes]
```

### TikTok
```
📱 texto na tela: [copy impactante, max 1-2 linhas]

📝 descrição: [até 300 caracteres]

#️⃣ hashtags: [3-5 super relevantes + 1-2 trending]
```

### LinkedIn
```
[HOOK — frase forte que abre o post]

[HISTÓRIA/INSIGHT — desenvolvimento em parágrafos curtos]

[REFLEXÃO/CTA — conclusão com chamada]

[HASHTAGS — 3-5 profissionais]
```
Tom: profissional mas acessível, storytelling pessoal funciona muito.

### X/Twitter
```
Tweet único: max 280 caracteres, forte e direto
Thread: 3-10 tweets encadeados com progressão lógica
```

## Gatilhos Mentais para Copy

Aplicar conforme o objetivo do post:

| Gatilho | Quando usar | Exemplo |
|---------|------------|---------|
| Escassez | Lançamentos, promoções | "últimas 24h" |
| Prova social | Depoimentos, resultados | "mais de 500 alunos" |
| Autoridade | Conteúdo educativo | "depois de 5 anos fazendo X" |
| Reciprocidade | Conteúdo gratuito | "salva esse post" |
| Curiosidade | Hooks de abertura | "ninguém te conta isso" |
| Urgência | Vendas, eventos | "começa amanhã" |
| Pertencimento | Comunidade | "se você é do tipo que..." |
| Contradição | Conteúdo viral | "pare de fazer X agora" |

## Regras de Qualidade

### Tom de voz
- Adaptar ao tom do cliente/marca (perguntar se não informado)
- Default: informal, acessível, como se estivesse conversando
- Lowercase para Instagram/TikTok (padrão atual)
- Profissional para LinkedIn

### O que evitar
- Clichês sem personalização ("venha fazer parte dessa jornada")
- CTAs genéricos ("clique no link da bio" sem contexto)
- Excesso de emojis (max 3-4 por post)
- Hashtags irrelevantes ou spam
- Copy que parece gerada por IA (usar skill `avoid-ai-writing`)

### Boas práticas
- Cada post com 1 objetivo claro (engajamento OU venda OU awareness)
- CTA específico e acionável
- Primeira frase = hook (a mais importante)
- Parágrafos curtos (1-3 linhas)
- Testar variações (oferecer 2-3 versões quando possível)

## Funcionalidades Extras

### Pack de legendas
Se solicitado, criar um pack com 5-10 legendas temáticas:
- Variação de tom (educativo, pessoal, venda)
- Diferentes formatos (curto, médio, longo)
- CTAs variados
- Prontas para usar, só adaptar detalhes

### Bio otimizada
Estrutura para bio de perfil:
```
[Quem você é / O que faz — 1 linha]
[Resultado ou prova social — 1 linha]
[CTA claro — 1 linha]
[Emoji] Link na bio ↓
```

## Checklist de qualidade

- [ ] O hook para o scroll nos primeiros 2 segundos?
- [ ] O CTA é claro e específico?
- [ ] O tom está alinhado com a marca?
- [ ] Está em lowercase (se Instagram/TikTok)?
- [ ] O texto soa humano (não genérico/IA)?
- [ ] As hashtags são relevantes e estratégicas?
- [ ] O texto respeita os limites de caracteres da plataforma?
- [ ] Há pelo menos um gatilho mental ativado?
