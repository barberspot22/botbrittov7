# Gestão de Crises em Redes Sociais

Skill para prevenir, gerenciar e recuperar-se de crises de imagem nas redes sociais.

## O que esta skill entrega

1. Protocolo de resposta a crises
2. Templates de comunicados
3. Estratégia de recuperação pós-crise
4. Scripts de resposta para comentários negativos
5. Plano de prevenção de crises

## Níveis de Crise

### Nível 1 — Ruído (comentários negativos isolados)
- Resposta individual, empática
- Não escalar, não apagar (a menos que ofensivo)
- Monitorar sem pânico

### Nível 2 — Incêndio (polêmica crescente)
- Comunicado público necessário
- Pausar conteúdo programado
- Atendimento ativo nos DMs
- Posicionamento claro e rápido

### Nível 3 — Crise (cancelamento/viral negativo)
- Comunicado oficial imediato
- Silêncio no feed (só o comunicado)
- Equipe focada em DMs e comentários
- Plano de recuperação em 7-14 dias
- Considerar assessoria jurídica se necessário

## Protocolo de Resposta

```
🚨 PROTOCOLO DE CRISE

1. PARAR — pausar todos os conteúdos agendados
2. AVALIAR — qual o nível? qual o tamanho? está crescendo?
3. OUVIR — ler tudo antes de responder (entender a reclamação real)
4. RESPONDER — comunicado empático, responsável, sem defensividade
5. AGIR — tomar ação concreta (não só palavras)
6. MONITORAR — acompanhar o desdobramento por 48-72h
7. APRENDER — documentar e criar protocolo para prevenir recorrência
```

## Templates de Comunicado

### Para erro/falha da marca
```
reconhecemos que [situação específica] não deveria ter acontecido.

entendemos a frustração de vocês e assumimos total responsabilidade.

já estamos [ação concreta que está sendo tomada].

a partir de agora, [medida preventiva para o futuro].

se você foi afetado, entre em contato pelo [canal] que vamos resolver individualmente.
```

### Para polêmica/mal-entendido
```
vimos as mensagens de vocês e queremos esclarecer.

[contexto real do que aconteceu, sem desculpas vagas].

nosso posicionamento é [posição clara].

valorizamos a opinião de cada um e estamos abertos ao diálogo.
```

### Para ataque injusto
```
[não responder diretamente ao ataque]
[reforçar valores e posicionamento da marca]
[mostrar provas/fatos se necessário]
[seguir em frente com conteúdo de valor]
```

## Respostas para Comentários Negativos

```
Reclamação legítima:
"entendo sua frustração, [nome]. vou te chamar no DM pra resolver isso pessoalmente."

Hate gratuito:
[ignorar ou ocultar — NUNCA responder com agressividade]

Trollagem:
[ignorar — bloquear se necessário]

Crítica construtiva:
"obrigado pelo feedback, [nome]. concordo que [ponto válido]. vamos melhorar nisso."
```

## Checklist de qualidade

- [ ] O nível de crise foi avaliado corretamente?
- [ ] O comunicado é empático (não defensivo)?
- [ ] Há ação concreta, não só palavras?
- [ ] O tom é profissional mas humano?
- [ ] Conteúdos agendados foram pausados?
- [ ] Há plano de monitoramento pós-crise?
