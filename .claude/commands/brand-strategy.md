# Estratégia de Marca para Redes Sociais

Skill para definir posicionamento, tom de voz, identidade visual e diretrizes de comunicação.

## O que esta skill entrega

1. Definição de posicionamento e proposta de valor
2. Tom de voz documentado com exemplos
3. Pilares de conteúdo estratégicos
4. Persona do público-alvo
5. Diretrizes visuais para redes sociais
6. Guia de comunicação da marca

## Coleta de Informações

Perguntar ao usuário:
1. **O que faz?** — produtos/serviços oferecidos
2. **Para quem?** — público-alvo ideal
3. **Diferencial** — o que te diferencia da concorrência
4. **Valores** — princípios e crenças da marca
5. **Referências** — marcas que admira (não necessariamente concorrentes)
6. **Objetivo** — o que quer alcançar com as redes sociais

## Posicionamento

### Framework de Posicionamento
```
PARA [público-alvo],
[marca] É [categoria]
QUE [diferencial único].
DIFERENTE DE [concorrentes/alternativas],
[marca] [razão para acreditar].
```

### Proposta de Valor
```
💎 PROPOSTA DE VALOR:
O que oferecemos: [benefício principal]
Para quem: [persona]
Como: [método/abordagem única]
Por quê é diferente: [diferencial competitivo]
```

## Tom de Voz

### Definição em 4 dimensões
```
📢 TOM DE VOZ DA MARCA:

1. Formal ←——————→ Informal
   [posição: X/10]

2. Sério ←——————→ Divertido
   [posição: X/10]

3. Respeitoso ←——————→ Irreverente
   [posição: X/10]

4. Técnico ←——————→ Acessível
   [posição: X/10]
```

### Card de Tom de Voz
```
NÓS SOMOS:          NÓS NÃO SOMOS:
✅ Acessíveis        ❌ Simplistas
✅ Diretos           ❌ Agressivos
✅ Especialistas     ❌ Arrogantes
✅ Autênticos        ❌ Forçados
```

### Exemplos Práticos
Para cada dimensão, dar exemplos de "como falamos" vs "como NÃO falamos":
```
✅ "bora resolver isso de um jeito simples?"
❌ "é com grande satisfação que apresentamos nossa solução inovadora"
```

## Persona do Público-Alvo

```
👤 PERSONA: [nome fictício]

📊 Demografia:
- Idade: [range]
- Gênero: [se relevante]
- Localização: [cidade/região]
- Renda: [faixa]
- Profissão: [área]

🧠 Psicografia:
- Valores: [o que importa pra ela]
- Frustrações: [dores principais]
- Desejos: [o que quer alcançar]
- Medos: [o que evita]

📱 Comportamento digital:
- Redes que usa: [plataformas]
- Horários ativos: [quando consome]
- Tipo de conteúdo que consome: [formatos]
- Como toma decisão de compra: [processo]
```

## Pilares de Conteúdo

Sugerir 4-5 pilares estratégicos alinhados com posicionamento + persona:

```
📌 PILARES DE CONTEÚDO:

1. 🎓 [PILAR EDUCATIVO] — [descrição + % do calendário]
2. 🎬 [PILAR BASTIDORES] — [descrição + %]
3. 💬 [PILAR CONEXÃO] — [descrição + %]
4. 📈 [PILAR PROVA SOCIAL] — [descrição + %]
5. 💰 [PILAR VENDA] — [descrição + %]
```

## Checklist de qualidade

- [ ] O posicionamento é claro e diferenciador?
- [ ] O tom de voz tem exemplos práticos?
- [ ] A persona é específica (não genérica)?
- [ ] Os pilares estão equilibrados (regra 80/20)?
- [ ] As diretrizes são acionáveis (não apenas teóricas)?
- [ ] Há coerência entre posicionamento, tom e pilares?
