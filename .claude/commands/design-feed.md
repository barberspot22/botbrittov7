# Design e Estética do Feed

Skill para planejar e criar identidade visual consistente para feeds de redes sociais.

## O que esta skill entrega

1. Planejamento visual do grid (padrão de cores/temas)
2. Paleta de cores derivada da marca
3. Diretrizes de design para posts
4. Templates HTML para posts
5. Recomendações de tipografia
6. Estilo fotográfico/visual

## Planejamento de Grid

### Padrões de grid populares

**Checkerboard (alternado):**
```
[claro] [escuro] [claro]
[escuro] [claro] [escuro]
[claro] [escuro] [claro]
```

**Linha por linha:**
```
[tema A] [tema A] [tema A]
[tema B] [tema B] [tema B]
[tema A] [tema A] [tema A]
```

**Diagonal:**
```
[cor 1]  [cor 2]  [cor 3]
[cor 3]  [cor 1]  [cor 2]
[cor 2]  [cor 3]  [cor 1]
```

**Rainbow/Gradiente:**
```
[tom 1]  [tom 1]  [tom 2]
[tom 2]  [tom 3]  [tom 3]
[tom 4]  [tom 4]  [tom 5]
```

## Paleta de Cores

A partir da cor principal da marca, criar sistema completo:

```
🎨 PALETA DE CORES:

Primária: [hex] — destaque, CTAs, títulos
Secundária: [hex] — complemento, ícones
Fundo claro: [hex] — backgrounds claros
Fundo escuro: [hex] — backgrounds escuros
Texto principal: [hex] — corpo de texto
Texto secundário: [hex] — subtextos
Accent: [hex] — destaques pontuais
```

## Diretrizes de Design

```
📐 DIRETRIZES VISUAIS:

Formato padrão: 1080x1350 (4:5) para feed, 1080x1920 (9:16) para stories/reels
Margem interna: 60px (nunca texto tocando a borda)
Border radius: [X]px para elementos arredondados
Sombras: [especificação]
Espaçamento: [padrão]
Filtro fotográfico: [descrição do estilo de edição]
```

## Templates HTML

Ao receber pedido de template, criar HTMLs exportáveis (semelhante ao carrossel) para:
- Post de dica/educativo
- Post de citação/frase
- Post de antes/depois
- Post de depoimento
- Capa de carrossel
- Story de texto

## Checklist de qualidade

- [ ] A paleta é coesa e derivada da marca?
- [ ] O grid tem padrão visual reconhecível?
- [ ] A tipografia é legível no mobile?
- [ ] As margens internas são respeitadas?
- [ ] Os templates mantêm identidade consistente?
- [ ] O estilo visual é diferenciador (não genérico)?
