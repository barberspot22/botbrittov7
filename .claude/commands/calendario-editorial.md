# Calendário Editorial para Redes Sociais

Skill para criar calendários editoriais estratégicos e completos, prontos para executar.

## O que esta skill entrega

1. Calendário visual organizado por semana/mês
2. Distribuição equilibrada de pilares de conteúdo
3. Sugestões de temas e formatos por dia
4. Datas comemorativas e oportunidades sazonais
5. Mix de formatos (reels, carrosséis, posts, stories)
6. Frequência otimizada por plataforma

## Informações Necessárias

Perguntar ao usuário (ou inferir do contexto):
1. **Nicho/negócio** — obrigatório
2. **Plataformas** — onde vai postar (default: Instagram)
3. **Frequência** — quantos posts por semana (default: 5)
4. **Período** — semana, quinzena ou mês (default: mês)
5. **Pilares de conteúdo** — se já tem definidos, usar. Senão, sugerir 4-5 pilares
6. **Objetivos** — crescimento, vendas, autoridade, comunidade?
7. **Produtos/serviços** — para incluir conteúdo de venda

## Pilares de Conteúdo

Se o usuário não tem pilares definidos, sugerir 4-5 baseados no nicho. Exemplos:

**Marketing Digital:**
- Educativo (dicas, tutoriais)
- Bastidores (dia a dia, processo)
- Cases/Resultados (prova social)
- Tendências (novidades do mercado)
- Venda (produtos, serviços, CTA)

**Saúde/Bem-estar:**
- Educativo (informações de saúde)
- Motivacional (inspiração, história)
- Prático (receitas, exercícios)
- Pessoal (rotina, bastidores)
- Venda (consultas, programas)

## Distribuição Estratégica

### Regra 80/20
- 80% conteúdo de valor (educativo, entretenimento, conexão)
- 20% conteúdo de venda (produtos, serviços, CTA direto)

### Mix de formatos por semana (5 posts)
```
Segunda: Carrossel educativo (pilar educativo)
Terça: Reels curto (pilar tendências)
Quarta: Post de bastidores (pilar pessoal)
Quinta: Carrossel de case/resultado (pilar prova social)
Sexta: Reels de venda leve (pilar vendas)
```

### Stories diários (complementar ao feed)
```
Manhã: Enquete/pergunta (engajamento)
Tarde: Bastidores/rotina (conexão)
Noite: Conteúdo rápido ou repost (alcance)
```

## Formato de Entrega

### Calendário Semanal
```
📅 SEMANA [X] — [período]

┌──────────┬──────────────┬──────────┬──────────────────┐
│ Dia      │ Formato      │ Pilar    │ Tema             │
├──────────┼──────────────┼──────────┼──────────────────┤
│ Segunda  │ Carrossel    │ Educativo│ [tema específico] │
│ Terça    │ Reels        │ Trend    │ [tema específico] │
│ Quarta   │ Post imagem  │ Pessoal  │ [tema específico] │
│ Quinta   │ Carrossel    │ Case     │ [tema específico] │
│ Sexta    │ Reels        │ Venda    │ [tema específico] │
└──────────┴──────────────┴──────────┴──────────────────┘

📱 Stories da semana:
- Segunda: [sugestão]
- Terça: [sugestão]
- ...
```

### Calendário Mensal
Mesmo formato, agrupado em 4-5 semanas com visão macro.

## Datas Importantes

Incluir automaticamente datas relevantes do mês:
- Feriados nacionais (Brasil)
- Datas comemorativas do nicho
- Eventos relevantes do mercado
- Datas comerciais (Black Friday, Dia das Mães, etc.)
- Trends sazonais previsíveis

## Regras de Qualidade

- Variar formatos (nunca 3 carrosséis seguidos)
- Alternar pilares (nunca 2 posts de venda seguidos)
- Pelo menos 1 reels por semana (prioridade no algoritmo)
- Sempre incluir stories como complemento
- Temas específicos, não genéricos ("5 erros de copy no Instagram" em vez de "dicas de copy")
- Pensar na jornada do seguidor (descoberta → confiança → conversão)

## Checklist de qualidade

- [ ] O calendário cobre todo o período solicitado?
- [ ] Os pilares estão equilibrados (regra 80/20)?
- [ ] Há variedade de formatos?
- [ ] Os temas são específicos e acionáveis?
- [ ] Datas comemorativas relevantes foram incluídas?
- [ ] A frequência é realista para o criador?
- [ ] Stories estão incluídos como complemento?
- [ ] Há pelo menos 1 conteúdo de venda por semana?
