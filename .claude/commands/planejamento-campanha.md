# Planejamento de Campanhas

Skill para criar campanhas completas de marketing em redes sociais — do briefing à execução.

## O que esta skill entrega

1. Briefing estratégico da campanha
2. Cronograma de execução
3. Conteúdos necessários (lista completa)
4. Copies e roteiros para cada peça
5. KPIs e métricas de acompanhamento
6. Orçamento sugerido (se tiver mídia paga)

## Fases da Campanha

### Fase 1 — Pré-campanha (teaser/aquecimento)
```
Duração: 3-7 dias antes
Objetivo: gerar expectativa
Conteúdos:
- Stories com contagem regressiva
- Posts enigmáticos/teaser
- Enquetes de antecipação
- Bastidores de preparação
```

### Fase 2 — Lançamento (impacto)
```
Duração: 1-3 dias
Objetivo: conversão máxima
Conteúdos:
- Post de lançamento (feed)
- Reels de apresentação
- Stories sequenciais de venda
- Live de lançamento (opcional)
- Email blast
```

### Fase 3 — Sustentação (middle)
```
Duração: 3-7 dias
Objetivo: manter momentum
Conteúdos:
- Depoimentos e prova social
- Behind the scenes
- FAQ em stories
- Reels educativos sobre o produto/serviço
```

### Fase 4 — Fechamento (urgência)
```
Duração: 1-3 dias
Objetivo: conversões finais
Conteúdos:
- Contagem regressiva
- Últimos depoimentos
- Storytelling de transformação
- Email de última chance
- Stories de urgência
```

## Briefing de Campanha

```
📋 BRIEFING DE CAMPANHA

🎯 Nome: [nome da campanha]
📅 Período: [data início] → [data fim]
💰 Objetivo: [vendas/leads/awareness/seguidores]
🎯 Meta: [número específico]
👥 Público: [segmento]
💵 Orçamento: [se houver mídia paga]

📱 Plataformas: [Instagram, TikTok, etc.]

📦 O que será promovido:
[produto/serviço/evento]

🔑 Mensagem principal:
[frase-chave da campanha]

📊 KPIs:
- [métrica 1]: meta [X]
- [métrica 2]: meta [X]
- [métrica 3]: meta [X]
```

## Cronograma de Execução

```
📅 CRONOGRAMA DE CAMPANHA

Pré-campanha (dia -7 a -1):
- Dia -7: [conteúdo]
- Dia -5: [conteúdo]
- Dia -3: [conteúdo]
- Dia -1: [conteúdo]

Lançamento (dia 1-3):
- Dia 1: [conteúdo + horário]
- Dia 2: [conteúdo + horário]
- Dia 3: [conteúdo + horário]

Sustentação (dia 4-10):
[grade de conteúdo diário]

Fechamento (dia 11-14):
[conteúdos de urgência]
```

## Checklist de qualidade

- [ ] O briefing está completo com objetivo e meta?
- [ ] As 4 fases estão planejadas?
- [ ] Cada dia tem conteúdo definido?
- [ ] Os KPIs são mensuráveis?
- [ ] Há conteúdo de prova social planejado?
- [ ] O fechamento tem urgência real?
