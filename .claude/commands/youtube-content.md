# Conteúdo para YouTube

Skill para criar e otimizar conteúdo para YouTube — títulos, descrições, thumbnails, roteiros e Shorts.

## O que esta skill entrega

1. Títulos otimizados para CTR (click-through rate)
2. Descrições com SEO completo
3. Briefings de thumbnail
4. Roteiros de vídeos (curtos e longos)
5. Scripts de YouTube Shorts
6. Tags e metadados otimizados

## Títulos Otimizados

### Fórmulas que funcionam
```
Numérico: "7 Erros que Destroem seu [resultado]"
Como: "Como [resultado desejado] em [tempo]"
Pergunta: "Por que [coisa surpreendente] Funciona?"
Contraste: "[Coisa barata] vs [Coisa cara] — Qual é Melhor?"
Desafio: "Tentei [desafio] por 30 Dias — Resultado Insano"
Revelação: "A Verdade sobre [tema polêmico] que Ninguém Conta"
Tutorial: "[Resultado] Passo a Passo (Guia Completo 2025)"
```

### Regras de títulos
- Máximo 60 caracteres (ideal: 40-55)
- Keyword principal no início
- Capitalizar cada palavra (Title Case em PT-BR)
- Usar números quando possível
- Gerar curiosidade sem ser clickbait vazio
- Sempre entregar 3 opções para o criador escolher

## Descrições

### Estrutura padrão
```
[Primeira linha: resumo + keyword principal — aparece na busca]

[2-3 linhas de contexto expandido com keywords relacionadas]

⏱️ TIMESTAMPS:
00:00 Introdução
XX:XX [Capítulo 1]
XX:XX [Capítulo 2]
...

🔗 LINKS:
[Link 1 — recurso mencionado]
[Link 2 — produto/serviço]

📱 REDES SOCIAIS:
Instagram: @...
TikTok: @...

#hashtag1 #hashtag2 #hashtag3
```

## Thumbnails

### Briefing de thumbnail
```
🖼️ THUMBNAIL: [título do vídeo]

📐 layout: [composição — ex: rosto à esquerda + texto à direita]
😮 expressão: [qual emoção facial — surpresa, concentração, etc.]
✏️ texto: [max 3-5 palavras, fonte grande, contrastante]
🎨 cores: [dominantes — contraste com YouTube vermelho]
🔍 elemento visual: [o que chama atenção — seta, círculo, objeto]

⚡ princípios:
- Legível em 2cm x 2cm (mobile)
- Contraste alto (evitar fundo branco genérico)
- Rosto humano sempre que possível
- Texto complementa, não repete o título
```

## Roteiros de Vídeo Longo (8-20min)

```
🎬 ROTEIRO: [título]

⏱️ duração estimada: [X min]
🎯 objetivo: [educar/entreter/vender]

━━━━━━━━━━━━━━━━━━━━━━━

[HOOK — 0:00-0:30]
"Abrir com promessa + curiosidade. Reter nos primeiros 30s."
[fala exata]

[INTRO — 0:30-1:00]
"Contexto rápido + credibilidade."
[fala exata]

[CONTEÚDO PRINCIPAL — 1:00-X:00]
Dividido em capítulos claros.

Capítulo 1: [título]
[fala exata]

Capítulo 2: [título]
[fala exata]

[CONCLUSÃO — últimos 2min]
"Resumo + CTA (curtir, inscrever, próximo vídeo)."
[fala exata]
```

## YouTube Shorts (< 60s)

Mesma estrutura que TikTok, adaptada:
- Vertical (9:16)
- Hook em 1-2s
- Texto na tela
- Duração ideal: 30-45s
- CTA: "inscreva-se" no final

## Checklist de qualidade

- [ ] Título tem keyword no início e gera curiosidade?
- [ ] Descrição tem SEO completo com timestamps?
- [ ] Briefing de thumbnail é específico e executável?
- [ ] Roteiro tem hook forte nos primeiros 30s?
- [ ] O roteiro está scriptado (falas completas)?
- [ ] Tags estão relevantes e completas?
- [ ] Há 3 opções de título para o criador escolher?
